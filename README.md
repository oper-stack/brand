# OperStack brand kit

The marks, the social cards and the rules for using them. Everything here is
generated from the HTML files next to each image, so a card can be rebuilt with
new text instead of redrawn.

## What is in here

| | |
|---|---|
| `avatar.png` | the mark on the dark ground, square, used as the profile picture everywhere |
| `og-*.png` | social cards, 1200x630, one per product |
| `og-*.html` | the source of each card. Edit the text, screenshot at 1200x630, replace the png |
| `linkedin/` | company page cover and copy |
| `product-hunt/` | the launch gallery |
| `BRAND.md` | colours, type, tone, and what not to do |

## The mark

Three bars, two teal and one gold, on near black. Teal `#3DB8A9`, gold
`#E8B84A`, ground `#0B1017`. The bars are the stack; the gold one is the layer
that is being worked on.

## Using these images

The cards are linked straight from the READMEs of the other repositories by raw
URL, so **do not rename or delete a file that is already in use.** Add a new one
instead. If a card must change, replace the image and keep the name.

Everything here is OperStack's own work and is meant for OperStack's own pages,
listings and profiles.
