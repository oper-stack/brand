## About (до 2000 знаков)

OperStack builds the tooling behind a pipeline that publishes to eleven content sites, with leads arriving from Google search and from ChatGPT, Perplexity and Copilot referrals. Every product is a piece of that pipeline, cleaned of client data and packaged so that one person can run it.

Free and open source:
• Fifteen gates: automated quality checks for MDX content sites, one command (npx @operstack/gates)
• An Astro starter that passes its own gates, with a generated llms.txt and an honest sitemap
• A Claude Code plugin for writing pages that answer engines quote

Paid:
• SEO, AEO and GEO audit: public signals collected automatically, findings priced per fix, delivered in five working days
• Site Kit: the full pipeline for launching a 300-page content site, with a page generator and a niche discovery module

Start with the free AI visibility check at oper-stack.com/ai-visibility.

## После создания страницы

1. Профиль → Опыт → Добавить: Founder, компания OperStack (выбрать из списка, тогда подтянется логотип), Sep 2026 to present, «I currently work here».
2. Карандаш в шапке профиля → Current position → выбрать OperStack. В шапке показывается только одна компания; MORE Group остаётся в опыте и в разделе «О себе».
3. Заголовок под именем заменить на строку из linkedin-texts.md, чтобы в нём были обе компании.
